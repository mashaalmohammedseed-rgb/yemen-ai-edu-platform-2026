# بوت رفيق الثالث الثانوي 🎓

بوت تيليجرام تعليمي ذكي لطلاب الثالث الثانوي في صنعاء.

## الميزات
- Onboarding ذكي (3 أسئلة)
- وضع الطوارئ (خطة 3 أيام)
- تتبع التقدم وسلسلة الدراسة
- دردشة مع AI (Gemini)
- مسارات: فهم / تدريب / مراجعة
- لوحة تحكم للمالك والأدمن
- اشتراك إجباري متعدد القنوات
- سجل تدقيق

## الإعداد
1. أضف Secrets في GitHub:
   - TELEGRAM_BOT_TOKEN
   - GEMINI_API_KEY
2. من Settings → Actions → Workflow permissions اختر "Read and write"
3. من Actions شغّل "Run Telegram Bot" يدوياً
4. أرسل /start للبوت
